# InnovateX 2026

A responsive college fest portal built using HTML, CSS and Vanilla JavaScript.

## Features

- Responsive landing page
- Hero section
- Live JavaScript countdown timer
- About section
- Interactive event cards
- Event schedule timeline
- Responsive image gallery
- Registration form
- Client-side form validation
- Responsive design

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
